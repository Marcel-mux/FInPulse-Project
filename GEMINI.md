# Model Collaboration Guidelines

- **UI & Frontend**: Bila menangani UI, komponen React/Tailwind, dan layout responsif: Utamakan penalaran Sonnet.
- **Backend & Arsitektur Data**: Bila menganalisis skema Prisma lintas file backend dan arsitektur data: Gunakan pemetaan Gemini Pro.
- **Operasional & Terminal**: Bila hanya menjalankan eksekusi terminal, commit git, atau pengecekan linting cepat: Gunakan mode Flash untuk efisiensi.
